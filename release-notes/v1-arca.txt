원본 등대 리워크 모드 위에 덮어쓰는 수정 빌드입니다. 바뀐 DLL만 들어 있고 맵은 원본 그대로 씁니다.

■ 고친 것

1) 다른 맵(특히 연구소)에서 쓰레기 메모리가 많이 생기던 것
- 언제: 이 모드를 깔아 두면 등대가 아닌 맵에서도 1분에 20~58MB씩 쓰레기 메모리가 생겼습니다. 이걸 치울 때 게임이 끊기고, RAM 클리너 목록에 이 모드가 나오던 이유입니다.
- 왜: 맵의 조명 하나하나가 매 프레임 "여기가 등대인가?"를 물으면서 매번 새 글자를 만들었습니다.
- 이제: 등대 판이 아니면 묻지 않고 바로 넘어갑니다. 연구소에서 1분에 20.5MB → 0.1MB로 줄었습니다.
- 확인: 개발자 게임 연구소 판에서 측정했습니다.

2) db 파일을 고치면 게임이 안 켜지던 것
- 언제: 모드 db 폴더의 json(전리품·아이템 등)을 하나라도 고치면 게임 접속이 막혔습니다.
- 왜: 서버가 파일마다 원본과 똑같은지 지문을 맞춰 보고, 다르면 모드를 멈췄습니다.
- 이제: 고친 json은 서버 창에 경고만 띄우고 그대로 씁니다. 고친 내용은 서버를 다시 켜야 적용됩니다.
- 확인: 게임이 메인 메뉴까지 켜지는 것은 확인했고, db를 고친 상태로는 아직 실험하지 않았습니다.

3) 기타
- 원작자가 나중에 넣은 부표 깜빡임 수정도 같이 들어 있습니다.

혹시 그래도 이상하면 원본 모드 압축을 다시 덮어쓰면 원래대로 돌아갑니다.
